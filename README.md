## Project Overview

Brown's Bakery is a modern bakery and café based in Centurion, Gauteng. The website was created to provide customers with information about the bakery, its products and services, locations, and ways to make enquiries or contact the business.

The website is designed for young adults, working professionals, families and local residents who are looking for freshly baked goods, custom cakes, beverages and a welcoming café experience.

## Project Goals

The main goals of the website are to:

- Provide an online presence for Brown's Bakery.
- Increase awareness of the bakery and its products and services.
- Allow customers to browse available products.
- Provide information about custom cakes, catering and special orders.
- Make it easier for customers to contact the bakery or submit an enquiry.
- Provide information about the bakery's locations and opening hours.
- Improve the website's usability, functionality and visibility through JavaScript and SEO.

## Website Pages

The website consists of five main pages:

- **Home (index.html)** – Introduces Brown's Bakery and highlights its bakery and café experience.
- **About Us (about.html)** – Provides information about the bakery, its background, mission and vision.
- **Products (products.html)** – Displays freshly baked goods, custom and celebration cakes, and café beverages.
- **Enquiry (enquiry.html)** – Allows customers to submit enquiries about custom cakes, catering and special orders.
- **Contact (contact.html)** – Provides contact details, opening hours, two locations, an interactive map and a contact form.

## Features and Functionality

The Brown's Bakery website includes the following features:

### General Website Features

- Navigation menu linking all five website pages.
- Bakery and café information.
- Product and service information.
- Images supporting the website content.
- Enquiry form for custom cakes, catering and special orders.
- Contact form for customer messages.
- Contact details and opening hours.
- Information about Centurion Mall and Eco Park.
- Internal links between relevant website pages.

### JavaScript Functionality

JavaScript was added to improve user interaction and website functionality.

The following features were implemented:

- **Product Search:** Allows visitors to search through the products displayed on the Products page. Products that do not match the search term are hidden.
- **Image Gallery Lightbox:** Allows visitors to click product images to view them in a larger display. The image can be closed using the close button, by clicking outside the image or by pressing Escape.
- **FAQ Accordion:** Allows visitors to expand and collapse frequently asked questions by clicking on the questions.

### Interactive Map

A Leaflet interactive map was added to the Contact page.

The map:

- Uses OpenStreetMap map tiles.
- Displays markers for Centurion Mall and the approximate Eco Park area.
- Allows visitors to zoom in and out.
- Allows visitors to move around the map.
- Displays location information when a marker is selected.

The markers indicate general location areas and should not be treated as confirmed bakery entrance coordinates.

### Forms and Validation

The website contains two forms:

**Enquiry Form**

The enquiry form allows customers to provide their contact information, select an enquiry category and describe their requirements.

The available categories include custom cakes, catering, special orders, product information, sponsorship, volunteering and other enquiries.

**Contact Form**

The contact form allows visitors to provide their name, email address, phone number, message type and full message.

HTML form validation and JavaScript are used to check required fields and input requirements.

The forms prepare a pre-filled Gmail message addressed to the bakery's contact email address. The visitor must review and send the message through their email account. The forms do not automatically send messages or use a server-side form submission system.
